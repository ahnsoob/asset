# DART 공시 기반 DCF 밸류에이션

금융감독원 전자공시(OpenDART) API에서 재무제표와 주식 수를 자동으로 가져와 **FCFF DCF** 로 주당 내재가치를 계산합니다.
결과는 콘솔 리포트, **수식이 살아있는 Excel**, JSON 으로 받을 수 있습니다.
공시에서 바로 가져오지 못해 **가정·대체한 값은 결과보다 먼저** 보여줍니다 (콘솔 맨 위, Excel 첫 시트 `Check`).

```
OpenDART API ──► dart.py (호출 + 캐시) ──► extract.py + accounts.py (계정 매핑)
                    │                           │
                    └─ document.xml (사업보고서 원문) ──► notes.py (주석에서 감가상각비 보완)
                                                │
                     연도별 표준 재무데이터 (매출, EBIT, D&A, CAPEX, NWC, 차입금, 현금, 주식수 …)
                                                │
                    model.py (가정 자동 산출 → WACC → FCFF 추정 → TV → EV → 주당가치)
                                                │
                       report.py (콘솔)   excel.py (xlsx, 수식)   cli.py (--json)
```

## 빠른 시작

```bash
pip install -r requirements.txt

# 1) API 키 없이 가상 회사 '샘플전자' 로 돌려보기
python -m dcf 샘플전자 --year 2024 --offline --cache-dir examples/sample_cache --excel sample.xlsx

# 2) 실제 회사 (https://opendart.fss.or.kr 에서 API 키 발급)
export DART_API_KEY=발급받은키
python -m dcf 005930 --year 2024 --beta 1.0 --price 55000 --excel samsung.xlsx
python -m dcf 삼성전자 --year 2024 --growth 8,7,6,4,3 --margin 12 --tg 2 --wacc 8.5
python -m dcf 삼성전자 --config examples/assumptions.example.json --json result.json
```

회사는 **회사명 / 종목코드(6자리) / DART 고유번호(8자리)** 로 지정합니다. 퍼센트는 `8`, `8%`, `0.08` 모두 같은 값입니다.

## 공시에서 자동 추출되는 항목

| 항목 | DART 출처 | 용도 |
|---|---|---|
| 매출액, 영업이익, 법인세차감전이익, 법인세비용 | 손익계산서 (`fnlttSinglAcntAll`) | 성장률, 마진, 유효세율 |
| 감가상각비·무형자산상각비 | 현금흐름표 조정 항목 → 없으면 **사업보고서 주석** (아래) | D&A/매출 |
| 유형·무형자산의 취득 | 현금흐름표 투자활동 | CAPEX/매출 |
| 이자의 지급 | 현금흐름표 | 세전 타인자본비용 |
| 유동자산·유동부채·현금·단기금융상품·단기차입금·유동성장기부채 | 재무상태표 | 영업 순운전자본 |
| 단기/장기차입금, 사채, 리스부채, 비지배지분, 자본 | 재무상태표 | 순차입금, 자본구조 |
| 발행주식총수 − 자기주식 | 주식의 총수 현황 (`stockTotqySttus`) | 주당가치 분모 |

- 계정은 XBRL `account_id` 로 먼저 찾고, 없으면 계정명(`Ⅰ.` 등 번호, 공백 제거 후) 정규식으로 찾습니다. 규칙은 `dcf/accounts.py` 에 있으니 회사별로 빠지는 계정이 있으면 패턴만 추가하면 됩니다.
- 어떤 공시 계정이 쓰였는지는 Excel **Sources** 시트에서 확인할 수 있습니다.
- 연결재무제표(CFS)가 없으면 별도(OFS)로 자동 전환합니다 (`--fs` 로 고정 가능).
- API 응답은 `.dart_cache/` 에 저장되어 같은 요청은 다시 호출하지 않습니다 (API 키는 캐시에 저장되지 않음).

## 주석에서 감가상각비 보완

`fnlttSinglAcntAll` 은 본문 재무제표만 주므로 현금흐름표에 감가상각비가 한 줄로 안 나오는 회사(예: 삼성바이오로직스)는 D&A 를 알 수 없습니다.
이때 사업보고서 원문(`document.xml`)을 받아 **연결(또는 별도) 재무제표 주석**에서 찾습니다.

| 순서 | 찾는 곳 | 비고 |
|---|---|---|
| 1 | 비용의 성격별 분류 — 감가상각비 및 상각비 (`ifrs-full_DepreciationAndAmortisationExpense`) | 손익계산서와 같은 범위 (중단영업 제외) |
| 2 | 현금흐름 조정내역 — 감가상각비 + 무형자산상각비 | 중단영업이 섞일 수 있음 |
| 3 | 유형·무형자산 변동표 — 감가상각비 + 상각비 | |
| 4 | (XBRL 태그가 없는 2023년 이전 원문) 성격별 분류 주석 **표 텍스트** | 당기/전기·단위(원/천원/백만원) 자동 인식 |

- 원문 셀의 XBRL 태그(`ACODE`, `ACONTEXT`)로 당기/전기, 연결/별도, 합계 행을 구분하고, 표시 단위는 API 값과 대조해 맞춥니다.
- 해당 연도 보고서의 당기 값이 우선이고, 없으면 다음 연도 보고서의 전기 값을 씁니다. API 가 가리키는 보고서가 일부만 고친 정정 공시라 주석이 없으면 같은 연도의 다른 사업보고서를 찾아봅니다.
- 사용권자산 상각은 제외합니다 (CAPEX 에 사용권자산 취득이 없으므로).
- 원문은 `.dart_cache/` 에 gzip 으로 캐시됩니다. 끄려면 `--no-notes`.

## 데이터 점검 — 가정·대체한 값을 먼저 확인

DCF 를 돌리면 결과보다 먼저 아래 목록이 나옵니다 (콘솔 맨 위 / Excel 첫 시트 `Check` / JSON `data_issues`).

| 구분 | 의미 | 예 |
|---|---|---|
| ⚠ 가정 | 공시에서 추출 실패 → 대체 가정값 | 감가상각비 없음 → D&A = CAPEX, 세율 → 법정세율, Kd → Rf+1.5% |
| ⚠ 기본값 | 공시에 없는 시장 데이터를 입력하지 않음 | Rf 3%, ERP 6%, β 1.0, 주가 없음 → 장부가 자본구조 |
| △ 조정 | 공시 기반 값을 범위 제한하거나 일부 연도만 사용 | 매출 CAGR 30% 초과 → 30% |
| ✚ 보완 | 본문에 없어 주석 등 다른 공시에서 채움 | 감가상각비 ← 연결주석 성격별 분류 |
| · 0 처리 | 계정이 없어 0 으로 계산 | 단기차입금, 비지배지분 |

```
┌─ [데이터 점검] 먼저 확인할 항목 4건  (보완·0 처리 6건)
│ ⚠ [기본값] 무위험이자율 (Rf): 3.00%
│     └ 공시에 없는 시장 데이터 — 입력하지 않아 기본값 사용
│ ✚ [보완] 감가상각비 (2025): 3,597억원
│     └ 현금흐름표 본문에 없음 → [주석] 비용의 성격별 분류 — 감가상각비 및 상각비 …
└─ ⚠ 기본값  △ 조정  ✚ 보완  · 0 처리
```

Excel 에서는 해당 셀이 색칠되고(주황 = 가정·기본값, 노랑 = 조정, 연두 = 보완, 회색 = 0 처리) 메모로 사유가 달립니다. `Check` 시트의 위치 링크를 누르면 그 셀로 이동합니다.

## 가정 (지정하지 않으면 공시 데이터에서 자동 산출)

| 가정 | 기본 산출 방식 | CLI |
|---|---|---|
| 매출 성장률 | 과거 매출 CAGR(−10%~30% 로 제한) → 마지막 해에 영구성장률로 선형 수렴 | `--growth` |
| 영업이익률, D&A/매출, CAPEX/매출, NWC/매출 | 최근 3개년 평균 | `--margin --da --capex --nwc` |
| 법인세율 | 최근 3개년 유효세율 평균, 이상치면 26.4% (법인세 24% + 지방세) | `--tax` |
| 자기자본비용 | CAPM: Rf 3.0% + β × ERP 6.0% (+ 규모 프리미엄). β = 직접 입력 > 피어 리레버드 > 1.0 | `--rf --beta --peer --erp --size-premium` |
| 타인자본비용 | 이자지급액 / 평균 차입금 (Rf ~ Rf+8% 로 제한), 없으면 Rf+1.5% | `--kd` |
| 자본구조 | 주가 입력 시 시가총액, 아니면 장부가 기준 D/(D+E) | `--debt-weight` |
| 잔존가치 | 영구성장 2.0% (또는 Exit EV/EBITDA 배수) | `--tg`, `--exit-multiple` |
| 할인 | 기중(mid-year) 할인 | `--no-mid-year` |

연도별 값은 `--growth 10,8,6,4,3` 처럼 쉼표로 넣거나 JSON 설정 파일(`--config`)에 리스트로 넣습니다.
**베타, 무위험이자율, 시장위험프리미엄, 주가는 공시에 없는 시장 데이터**이므로 직접 넣는 것을 권장합니다.

## 피어 베타 리레버링

유사기업(피어) 베타로 대상회사 베타를 만드는 기능입니다 (Hamada 식).

```
① 피어별 언레버드 β_U = β_L / (1 + (1 − t) × D/E)
② 대표 β_U          = 피어 β_U 의 중앙값 (또는 평균, --peer-method mean)
③ 대상회사 β_L      = 대표 β_U × (1 + (1 − t_대상) × D/E_대상)      → CAPM → Ke → WACC
```

- **대상회사 D/E**: WACC 에 쓰는 D/(D+E) 를 D/E 로 바꿔 사용 (주가 입력 시 시가, 아니면 장부가, `--debt-weight` 지정 시 목표 자본구조). 베타와 WACC 가중치가 같은 자본구조를 쓰게 됩니다.
- **대상회사 세율**: 모델 법인세율 (유효세율 평균 또는 `--tax`).
- **피어 세율**: 피어별로 지정, 없으면 26.4% (`--peer-tax` 로 변경).
- **피어 D/E**: 직접 입력하거나, 생략하면 **DART 에서 자동 산출**합니다. D = 차입금+사채+리스부채, E = 피어 주가(`price`)를 주면 시가총액, 아니면 장부가 자본.
- **피어 언레버드 β 를 이미 알고 있으면** (블룸버그 등) 그대로 넣으세요. D/E 없이 그 값을 쓰고, 대상회사 D/E 로 리레버링만 합니다. 언레버드 β 와 (레버드 β + D/E) 를 섞어 넣어도 됩니다.
- 베타 우선순위: `--beta` 직접 입력 > 피어 리레버드 베타 > 1.0

```bash
# 명령행: 이름:베타[:D/E[:세율]]  (D/E 생략 → 이름을 회사명/종목코드로 보고 DART 조회)
python -m dcf 005930 --price 55000 --peer 000660:1.25 --peer LG전자:1.10:45%:24 --peer 삼성전기:1.05

# 언레버드 β 를 아는 피어: 이름:레버드β:언레버드β  (레버드 β 는 비워도 됨)
python -m dcf 005930 --price 55000 --peer-u SK하이닉스:1.25:1.08 --peer-u LG전자::0.92

# JSON 파일 (examples/peers.example.json 참고)
python -m dcf 005930 --price 55000 --peers peers.json --peer-method mean
```

```json
[
  {"name": "피어A", "beta": 1.25, "de_ratio": 0.20, "tax_rate": 0.242},
  {"name": "피어B", "beta": 0.95, "debt": 300000000000, "equity": 1500000000000},
  {"name": "피어C", "beta": 1.10, "company": "000660", "price": 180000},
  {"name": "피어D", "beta": 1.30, "unlevered_beta": 1.08}
]
```

**Excel 에서 직접 입력하기** — 모든 Excel 출력에 **Peer Beta** 입력표가 들어 있습니다 (피어를 안 넣고 돌려도 빈 표가 생김).

1. 피어명과 **언레버드 β** 를 넣거나, **레버드 β + D/E** (또는 부채·자본) 를 넣습니다. 세율 칸이 비면 26.4% 를 씁니다.
2. 언레버드 β 칸이 채워진 행은 그 값을 우선 쓰고, 아니면 언레버링 수식으로 계산합니다.
3. 중앙값/평균(집계 방식 1/2) → 대상회사 D/E·세율로 리레버링된 β 가 자동 계산됩니다.
4. Assumptions 의 **'피어 리레버드 β 사용' 을 1** 로 두면 적용 베타 → Ke → WACC → 주당가치까지 다시 계산됩니다 (0 이면 '베타 직접 입력값' 사용).

피어의 관측 베타(β_L) 자체는 공시에 없으므로 증권사 HTS·블룸버그 등에서 가져와 넣어야 합니다 (통상 주간 2년 또는 월간 5년, KOSPI 대비).

## Excel 모델 출력 (`--excel`)

계산 과정 전체가 **셀 수식으로 연결된** 모델이 만들어집니다. 예시: [`examples/sample_dcf_model.xlsx`](examples/sample_dcf_model.xlsx)

```
Check (데이터 점검) │ Historical ──► Assumptions ──► DCF ──► Sensitivity ──► Summary
(공시 원본 → 파생지표 → 평균/CAGR)  (WACC)   (FCFF → EV → 주당가치)
```

| 시트 | 내용 |
|---|---|
| **Check** | 데이터 점검 — 가정·기본값·조정·보완·0 처리 항목, 사유, 해당 셀 링크 (파일을 열면 처음 보이는 시트) |
| **Summary** | 주당가치, 상승여력, EV 분해, WACC 등 핵심 결과 + 계산 흐름 설명 |
| **Historical** | ① DART 공시 원본 값(회색) ② 파생 지표 수식(EBITDA, NWC, 순차입금, 마진, 유효세율, 이자율…) ③ 최근 N년 평균·매출 CAGR |
| **Assumptions** | CAPM(Rf, β, ERP) → Ke, Kd, 세율, D/(D+E) → WACC, 영구성장률, 현금·차입금·비지배지분, 주식수, 주가 |
| **Peer Beta** | 피어 입력표 (언레버드 β 직접 입력 또는 β+D/E 로 언레버링) → 중앙값/평균 → 대상 D/E 로 리레버링 → 적용 베타 |
| **DCF** | 연도별 가정 → 매출 → EBIT → NOPAT → +D&A −CAPEX −ΔNWC = FCFF → 할인 → TV → EV → 주주가치 → 주당가치. 행마다 '산출 근거' 설명 |
| **Sensitivity** | WACC × 영구성장률 주당가치 표 (수식이라 가정 변경 시 함께 갱신) |
| **Sources** | 각 항목에 매칭된 공시 계정 (재무제표 구분, 계정명, XBRL ID) |

- 글자색: **파란색 = 입력값**, **초록색 = 다른 시트 연결**, 검정 = 계산식. 노란 칸 = 핵심 결과.
- 공시에서 자동 산출된 가정(성장률, 마진, D&A·CAPEX·NWC 비율, 세율, Kd, 부채비중)은 Historical 시트를 참조하는 수식으로 들어갑니다. 직접 지정한 가정이나 범위 제한(clip)이 걸린 값은 숫자로 들어갑니다.
- 어느 셀이든 숫자로 덮어쓰면 그 뒤 계산이 전부 다시 됩니다 (예: 2026E 영업이익률만 바꾸기, 베타 바꾸기).
- LibreOffice 가 설치되어 있으면 계산 결과값도 파일에 저장되어 미리보기에서도 숫자가 보입니다. 없으면 Excel 에서 열 때 계산됩니다.

## 계산 방식

```
FCFF   = EBIT × (1 − t) + D&A − CAPEX − ΔNWC
TV     = FCFF(N+1) / (WACC − g)            ← N+1년은 매출 × (1+g) 로 정규화해 다시 계산
EV     = Σ FCFF_t / (1+WACC)^(t−0.5) + TV / (1+WACC)^(N−0.5)     (기중 할인 시)
주주가치 = EV + 현금·단기금융자산 − (차입금 + 사채 + 리스부채) − 비지배지분
주당가치 = 주주가치 / (발행주식총수 − 자기주식)
```

## 한계 / 주의

- 평가 기준일은 기준연도 말입니다 (분기 데이터 미반영).
- 리스부채를 차입금에 포함하는 IFRS 16 방식이지만, 사용권자산 취득은 CAPEX 에 포함되지 않습니다.
- 금융업(은행·보험·증권)은 FCFF DCF 에 맞지 않습니다 (매출/운전자본 개념이 다름).
- 관계기업투자·투자부동산 같은 비영업자산은 EV 에 따로 더하지 않습니다. 비중이 크면 결과에 수동으로 반영하세요.
- 현금흐름표와 주석 어디에서도 감가상각비를 못 찾으면 D&A = CAPEX 로 가정하고 데이터 점검 맨 위에 표시합니다.
- 중단영업(인적분할·매각)이 있는 해는 손익계산서가 계속영업 기준이라 과거 연도와 범위가 다를 수 있습니다. 성장률·마진은 직접 확인하세요.
